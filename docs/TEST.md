# 功能自测说明

> 本文档记录本项目**实际执行过**的自动化测试与人工验收步骤，逐条对应需求清单。
> 测试环境：Windows 10 / Python 3.13.16 / uv 0.11.14 / FastAPI 0.156.4 / Edge（Chromium）。

## 1. 启动测试环境

```bash
# 1. 安装依赖
cd backend
uv sync

# 2. 启动后端（默认 http://127.0.0.1:8000）
uv run serve
```

另开终端：

```bash
# 3. 启动静态前端（或直接打开 frontend/index.html）
cd ..
./start-frontend.ps1     # Windows
# ./start-frontend.sh    # Linux / macOS
```

确认 `frontend/js/config.js` 中的 `API_KEY` 与 `backend/.env` 的 `DT_API_KEY` 一致；页面右上角应显示 **服务正常**。

### 2.4 关键断言示例

- 生成 10 题试卷：题目数恒为 10，所有题目分值之和恒为 100；
- 科目一请求多选题：返回 `4003`；
- 科目一请求 100 题：返回 `4001`，并给出可用题量 52；
- 下载 MD：`Content-Type: text/markdown`、包含 `filename*=UTF-8''`、包含标准答案/解析/答案速查表；
- 空白卷：不包含标准答案，包含答题卡；
- 上传响应：不包含 `answer` / `explanation` 字段（防止前端直接看答案）；
- 全部答对：100 分、正确率 100%、`grade=优秀`、无错题；
- 故意错 2 题：80 分、`wrong_count=2`、`passed=false`、错题包含正确答案与解析；
- 错题 MD：包含错题汇总、正确答案、解析；
- 无 API-KEY：401 且带 `WWW-Authenticate`。

## 5. API 冒烟命令

```bash
KEY="sk-dtk-local-2026-change-me"
BASE="http://127.0.0.1:8000"

# 1. 鉴权 + 健康检查
curl -s "$BASE/api/v1/health" -H "Authorization: Bearer $KEY"

# 2. 生成试卷
curl -s "$BASE/api/v1/exams/generate" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"subject":"subject1","question_count":10,"question_types":["single","judge"],"chapters":[]}'

# 3. 下载试卷（把 exam_id 替换为上一步返回值）
curl -L "$BASE/api/v1/exams/exam_xxx/download" \
  -H "Authorization: Bearer $KEY" -o exam.md

# 4. 知识问答
curl -s "$BASE/api/v1/chat" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"message":"高速公路最低限速是多少？","history":[],"session_id":"chat_demo_001"}'

# 5. 上传题库
curl -s "$BASE/api/v1/questions/upload" \
  -H "Authorization: Bearer $KEY" \
  -F "file=@samples/sample_bank.md"

# 6. 提交阅卷（paper_id、question_id 替换为上传返回）
curl -s "$BASE/api/v1/grading/submit" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"paper_id":"paper_xxx","answers":[{"question_id":"q001","answer":["A"]}],"duration_seconds":120}'
```

## 7. 已知限制

1. **内置题库规模**：科目一 52 题、科目四 40 题。若请求题量超过当前筛选可用量，会返回明确错误；可在 `backend/app/data/questions_subject*.json` 按相同结构扩充。
2. **知识库为本地检索**：当前 40 个结构化知识点，使用关键词/同义归一/字符相似度/上下文拼接匹配，不依赖外部大模型，结果可控但语义泛化能力有限；可继续扩充 `knowledge_base.json`。
3. **聊天历史保存在浏览器**：换浏览器/清缓存/无痕模式不会保留，也不会跨设备同步；这是隐私友好的本地存储设计。
4. **文件格式**：仅支持 UTF-8 / GBK 编码的纯文本 `.txt` / `.md`，不支持 PDF、Word、图片 OCR；题库格式需遵循文档说明。
5. **固定 API-KEY**：静态前端中的 key 对使用者可见，适合内网工具；公网部署应在网关层增加用户级鉴权。
6. **单机存储**：试卷/题库/结果保存在 `backend/.data` 文件，默认 24/24/72 小时过期；多实例部署需共享存储或改造为数据库。
7. **多选判分**：与真实驾考一致，全部选对才得分，不支持部分得分。
